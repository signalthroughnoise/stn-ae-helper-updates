# STN - AE Helper — updates

Release channel for the STN - AE Helper Premiere Pro panel.

- `version.json` — the current version; the panel's update check reads this.
- `STN-AE-Helper.zip` — the full panel (CSXS/ at the top level); the panel's
  Update button downloads and installs this.

To publish an update: replace both files with the new build and push to `main`.
